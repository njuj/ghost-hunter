# Security Policy

## Reporting a vulnerability

ghost-hunter is a defensive tool: it scans the memory of running processes on a machine you control
to flag injected or hollowed code. It reads process memory only — it changes nothing.

If you find a security issue in the tool itself, please report it privately via this repository's
**Security → Advisories → Report a vulnerability**, rather than opening a public issue.

## Scope

Run ghost-hunter only on systems you own or are explicitly authorized to inspect.
